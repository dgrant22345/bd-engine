Connections export

How to export your LinkedIn connections to CSV

LinkedIn will send you a file of your own first-degree connections on request. This guide covers where to ask for it, what the file contains, and the handful of problems that stop it importing cleanly elsewhere.

Published by BD Engine November 12, 2026 6 minute guide

Request the file from LinkedIn

LinkedIn provides your first-degree connections as part of its own data download. You request it from your account settings; nothing is installed and no third party signs in to your account.

  1. On LinkedIn, open the Me menu and choose Settings & Privacy.
  2. Open Data privacy, then Get a copy of your data.
  3. Choose the connections option if LinkedIn offers it. If it only offers the larger data archive, request that; the connections file is inside it.
  4. Select Request archive and confirm your password if asked.
  5. Wait for LinkedIn's email, download the archive, and unzip it. The file you need is Connections.csv.

Labels and timing are LinkedIn's to change. The email can arrive within minutes or take up to a day, and the menu wording is revised from time to time. If the options differ, follow LinkedIn's current instructions.

What Connections.csv contains

The file begins with a short notes block from LinkedIn, followed by one header row and one row per connection. The columns are:

  • First Name and Last Name
  • URL: the person's public profile address
  • Email Address: present only for connections who allow their connections to see it
  • Company and Position: the current employer and title shown on the profile
  • Connected On: the date you connected

It does not contain phone numbers, work history, messages, or anything about second-degree connections. Most email cells are blank, and that is expected: the notes block at the top of the file says so.

Problems that make an import fail

The download is a zip archive

Upload the Connections.csv file from inside the archive, not the archive itself.

The file was opened and saved again in a spreadsheet

Saving from a spreadsheet application can change the separator to a semicolon or a tab, change the text encoding so that accented names break, or produce an .xlsx workbook. If you need to edit the list, save it as CSV. BD Engine reads comma, semicolon, and tab-separated files and detects the common encodings, but it does not open workbooks.

The columns were renamed or removed

An import needs a name and a company for each person. A row with neither is skipped, and a file with no company column cannot be used. BD Engine states which column is missing and which columns it found, so the fix is usually to restore one heading.

The list came from another tool

Exports from a CRM or contact manager often use headings such as "Full Name", "Organization", or "Job Title". These are recognised. A heading BD Engine cannot match is ignored; it does not stop the import.

What the file is useful for

On its own, the export is a long list sorted by nothing in particular. It becomes useful when it is grouped by employer and compared with something current, such as which of those employers are hiring.

  • For business development: see which target accounts already contain people you know, and whether any of them work in talent acquisition or lead a team that is hiring.
  • For a job search: see which employers with relevant openings include someone who could tell you about the team.

A connection is context, not consent. The export shows that you are connected. It does not show how well you know the person or whether they want to hear from you about work. Review each contact before writing, and write to people individually.

Check your target list before you import

BD Engine reads the file you upload and never signs in to LinkedIn. Before creating an account, you can test which of your target employers use a public job board it can read. The audit runs in your browser and needs no sign-up.

Before you upload
