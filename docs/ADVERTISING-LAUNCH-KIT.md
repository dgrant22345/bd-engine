## Measure results

Use the private operator acquisition report, and keep platform impressions/clicks in the included `campaign-scorecard.csv`. Leave values blank until they are observed. Never label blank cells as zero activity. Public health or billing readiness is not a traffic report.

Compare manual audits, signups, activation, confirmed paid subscriptions, and returning customers. Keep sample-audit activity separate from audits of a visitor's own list. A click or checkout start is not a paid customer. Internal, demo, and QA traffic must be excluded; `BD_ANALYTICS_TEST_EMAILS` can exclude the test inbox used for provider verification.

Useful calculations:

- Signup rate = signups / campaign visitors, when both counts have the same source and observation period.
- Activation rate = activated customers / signups, using the report's activation definition.
- Customer acquisition cost = spend / confirmed new paid customers, only when that denominator is nonzero.
- Returns = visits during days 7–13 after signup; report only when the full 14-day observation window closes.

The existing report attributes sources; it does not prove that an ad caused a purchase. Consider the $5/$10 monthly price when choosing spend caps, and collect actual conversion and retention data before estimating profitable acquisition costs.

If there are few visitors, improve distribution. If visitors try the free tool but don't sign up, interview willing users about the next-step value. If signups don't activate, work on onboarding. Use measured behavior to choose the next improvement.
