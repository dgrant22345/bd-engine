have a company list.

**Copy:** A careers page, a contact list, and an overdue follow-up each hold part
of the answer. BD Engine brings them into one ranked daily queue. Start by
checking your target list: audit up to 50 public careers URLs, see which hosts
are recognized, and export the result. No signup required for the audit.

## Use and measurement

Start with one recruiter message at a time and keep job-seeker traffic on its
dedicated page. In the existing analytics view, compare each campaign's audit
completions, signup starts, completed signups, and activated workspaces. Evaluate
activation with real user data; synthetic demo activity is a separate cohort.
Treat message tests as experiments until there is enough traffic to compare them.

For a paid variant, use `utm_medium=paid_social` and a distinct `utm_content` for
each creative. Use the commercial launch checklist to decide when to spend; this
file does not set a budget or launch an ad campaign.

Describe public hiring activity and recognized ATS hosts precisely. A recognized
host does not guarantee complete coverage or fresh role data. A mapped contact
does not guarantee a referral. Outreach drafts require review and manual sending.
Publish customer statistics, testimonials, review ratings, or refund promises
only when the underlying evidence or policy is available.
