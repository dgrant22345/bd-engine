# Security policy

BD Engine is in limited commercial beta. Security and privacy reports are
welcome for the currently deployed cloud application and the latest release
candidate on `deploy/perf-restore`.

## Report a vulnerability

Email `dgfinance15@gmail.com` with the subject `BD Engine security report`.
Include the affected feature, reproduction steps, impact, and a safe way to
contact you. Do not include passwords, API keys, full customer exports, database
backups, payment details, or another person's private data.

Please do not open a public issue for a suspected vulnerability or test against
customer workspaces. Use a test account and stop if testing could alter data,
interrupt service, send messages, or create charges.

Receipt will be acknowledged as operator capacity permits. No response-time,
bounty, or disclosure-timeline commitment is offered until a formal security
program is staffed.
